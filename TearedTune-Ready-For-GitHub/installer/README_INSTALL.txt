TEARED TUNE V3  -  VST3 pitch-correction effect for Windows 64-bit
==================================================================

INSTALL (about 1 minute)
------------------------
1. Extract this ZIP (right-click > Extract All).
   TIP: if Windows blocked the ZIP, right-click the ZIP FIRST > Properties >
   tick "Unblock" > OK, and then extract.

2. You will see a FOLDER named:   TearedTune V3.vst3
   (It is a folder, not a single file. That is normal for VST3 on Windows.)

3. Copy the whole "TearedTune V3.vst3" folder into:

        C:\Program Files\Common Files\VST3

   Windows will ask for administrator permission - click "Continue".

4. Open FL Studio:
      Options > Manage plugins > "Find installed plugins" (Start scan)

5. Use it - it is an EFFECT, so put it on a MIXER INSERT:
      Mixer > pick the insert your vocal is routed to > click an empty
      FX slot > "TearedTune V3"
   (Route your vocal channel or Edison/audio clip to that insert.)

QUICK START
-----------
1. Set KEY and SCALE to match your song (or click the keys to choose notes).
2. Set VOICE RANGE to your voice type (Low / Mid / High).
3. Choose a style at the top: NATURAL (subtle), CLASSIC, or HARD TUNE (robot effect).
4. Fine tune with RETUNE SPEED (0 = instant/robotic, higher = more natural).
5. KEEP VIBRATO keeps natural vibrato while the centre of the note is fixed.
6. Use ONE voice at a time (it is a monophonic tuner: no chords / full mixes).

NOTES
-----
* Latency: about 8 ms. FL Studio compensates automatically (plugin delay compensation).
* Works best on a clean, dry, mono vocal. Reverb/backing vocals on the same track confuse any pitch detector.
* Not in the list?  Options > Manage plugins > tick "Verify plugins" and scan again.
* Windows SmartScreen / antivirus may warn: the plugin is not code-signed (certificates cost money).
  You built it yourself from the source.

To uninstall: delete the "TearedTune V3.vst3" folder from C:\Program Files\Common Files\VST3
